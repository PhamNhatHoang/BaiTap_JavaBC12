# Java BC12 Exercises

Repository tổng hợp bài tập trong quá trình học Java Core tại lớp BC12. Nội dung được tổ chức theo từng buổi học, từ cú pháp cơ bản đến hàm, mảng và các bài toán thực hành.

![Java](https://img.shields.io/badge/Java-Core-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Status](https://img.shields.io/badge/Status-Learning-2563EB?style=flat-square)

## Nội dung học tập

- Biến, kiểu dữ liệu và toán tử.
- Nhập xuất dữ liệu với `Scanner`.
- Cấu trúc điều kiện `if/else` và `switch`.
- Vòng lặp.
- Hàm và cách tổ chức chương trình.
- Mảng và xử lý dữ liệu cơ bản.
- Các bài toán thực hành như:
  - Tìm giá trị lớn nhất.
  - Kiểm tra số chẵn/lẻ.
  - Máy tính cơ bản.
  - Tính thuế thu nhập cá nhân.
  - Tính cước chuyến xe và in hóa đơn.

## Cấu trúc repository

```text
java-bc12-exercises/
└── baiTap_JavaBC12/
    └── src/
        ├── baiTap_buoi.../
        └── baiTap_buoi8/
```

Mỗi package tương ứng với một buổi học hoặc một nhóm bài tập.

## Yêu cầu

- JDK 8 trở lên
- IntelliJ IDEA, Eclipse, NetBeans hoặc trình soạn thảo hỗ trợ Java

## Chạy bài tập

1. Clone repository:

   ```bash
   git clone https://github.com/PhamNhatHoang/java-bc12-exercises.git
   ```

2. Mở thư mục `baiTap_JavaBC12` bằng IDE.
3. Chọn class có phương thức `main` cần chạy.
4. Run class và nhập dữ liệu theo hướng dẫn trên console.

Ví dụ chạy bằng terminal từ thư mục `src`:

```bash
javac baiTap_buoi8/BaiTapHam.java
java baiTap_buoi8.BaiTapHam
```
